### ✔️ **Block Type**

Defines **what kind of content element** the block **is** — its **semantic role or function**.

Examples:

- **Text / Paragraph**
- **Heading**
- **Quote**
- **List**
- **Code**
- **Image**
- **Table**
- **Callout**
- **Divider**
- **Embed**

---

### ✔️ **Block Style**

Defines **how that block is visually presented** — its **appearance, hierarchy, or formatting preset**.

Examples for text blocks:

- **Normal text**
- **Heading 1**
- **Heading 2**
- **Subtitle**
- **Caption**
- **Body Large / Small**
- **Bold / Italic / Underline themes**
